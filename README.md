## Overview

My personal portfolio — a fast, bold, single-page site with a strong editorial type treatment, built as a static PWA. It presents who I am, my technical skills, certifications, and projects, and links to a downloadable résumé.

## ✨ Highlights

- 🎨 **Striking, high-contrast design** with large display typography and interactive touches
- 🧰 **Technical Skills** and **Certifications** sections
- 📄 **Downloadable résumé** (`Sayak_Satpathi_Resume.pdf`)
- ⚡ **Installable PWA** — service worker (`sw.js`) for offline-friendly loading
- 🔍 **SEO-ready** — `sitemap.xml`, `robots.txt`, and descriptive metadata
- 📐 **Fully responsive** across mobile, tablet, and desktop

## 🧱 Tech Stack

- **HTML5 + Tailwind CSS + vanilla JavaScript**
- Icons via **Lucide**, custom interactions in `js/interactive.js`
- Deployed as a static site (GitHub Pages / Netlify — `netlify.toml`)

## 🚀 Run Locally

```bash
npx serve .          # or open index.html directly
```

```

├── images/
```
